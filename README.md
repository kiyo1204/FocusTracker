# Focus Tracker(集中度計測アプリ)

## 概要
　このアプリはWebカメラを用いてモニターに集中しているかどうか判定するものです.

## 動機
　このアプリを制作した理由は, 最近オンラインの講義がある中で動画を見ているときの集中度合を可視化することで勉強時のクセを見つけ, 学習の効率を高められるのではないかと思い制作しました.

## ⛏️使用技術
- **フロントエンド**: Tkinter
- **バックエンド**: Python
- **コンピュータビジョン**: OpenCV, MediaPipe Pose
- **機械学習**: Tensorflow/Keras, Scikit-Learn(データ分割)
- **非同期処理**: Subprocess, Threading

>**MediaPipeとは**:<br>
　Googleが開発した、動画や静止画から顔・手・体の骨格などをリアルタイムに検出・追跡するオープンソースの機械学習フレームワークです. これによって自動的に目や鼻などを検知します.

## ⚙️機能・特徴
### 機能
- 📷データの収集, モデル作成も同じアプリで可能 
- 🚨ログも表示されるためエラー監視や学習状況が一目で行えます

### 特徴
- 📱Tkinterを使用しているため, GUIでの操作が可能
- 💻非同期処理を用いて複数タスクの動作を実現

## 🧠工夫した点
1. **データ収集について**
   - **相対座標化**:<br>
   　データ収集の際に目や鼻などの座標を取得するが, この座標の原点と鼻の位置にすることで座っている位置や距離の変化に強くしました.
   - **EMAフィルター**:<br>
   　座標取得時に発生する振動を平滑化し, 汎化性能を高めます.
   - **外れ値検知**:<br>
     MediaPipeには取得データにVisibility(信頼度)値があり, 閾値を設定することで誤検知を自動的に破棄します.

2. **モデル作成について**
   - **畳み込み層の追加**:<br>
   　この層によって時間経過による集中度の変化(短期間)を検出しやすくしています.
   - **LSTM層の採用**:<br>
   　この層によって長期的な情報(これまでのほぼ全て)で集中度の変化を捉え, 最終的な予測を出力します.
  >**畳み込み層とは:**<br>
  　畳み込み層は主に画像認識に使われる手法ですが, 今回のような一次元データにも有効です. 二次元データでは空間的な特徴を得るのに対し, 一次元データでは時間的な変化を抽出することが可能です.  
  >**LSTMとは:**<br>
  　LSTMとは*Long Short-Term Memory*の略で, 過去の不要なデータを忘れる(削除)ことで昔の重要なデータを保持し続ける手法です. <br>※認知科学での長期・短期記憶と単語は一緒ですが, ニュアンスは少々異なります(LSTMでは短期記憶が長期記憶に変移することはない).

## 📥インストールについて
### 制作環境
- Python 3.11(64bit)
- MediaPipe 0.10.32
- Tensorflow 2.21.0

### インストール方法
### 方法①(Python環境必要必須)
1. **保存したいディレクトリに移動する**
2. **右クリックでターミナルを起動する**<br>
　保存したいディレクトリがカレントディレクトリになっていることを確認
   <img width="1135" height="505" alt="Install_file" src="https://github.com/user-attachments/assets/ff7fbe69-e074-4375-9543-624b7d65667f" />
3. **レポジトリのデータをダウンロード**
   ```bash
   git clone https://github.com/kiyo1204/FocusTracker
   ```
4. **必要なモジュールのインストール**
   ```bash
   pip install -r requirements.txt
   ```
5. **ショートカットの設定(任意)**<br>
　ショートカットを設定することで, より楽に起動することができます. ショートカットの設定は```FocusTracker/bat/FocusTracker.vbs```と指定します.


### 方法②(Python環境必要なし)
**.exeを使用した方法**<br>
Githubのリリース欄にPre-releaseしてあるzipファイルをダウンロードします. 解凍後, exeファイルをダブルクリックで起動します.
※ この方法では集中度の予測のみ行えます. 


## 🖱️使い方
### 方法①の場合
1. **起動**:<br>
　ディレクトリ内のショートカットを起動します.
2. **データ収集**:<br>
　開発者モードに飛び, 学習データ(集中データ, 非集中データの二種類)を取ります(データ数はどちらも多いことが好ましい).
3. **モデル作成**:<br>
　開発者モードのモデル作成タブでモデルを作成します.
4. **予測**:<br>
　予測ページに飛び, スタートボタンを押すとカメラが起動します.

### 方法②の場合
ダウンロードしたexeファイルを実行し, 予測のスタートボタンを押すとカメラが起動します.
